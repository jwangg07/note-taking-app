# FastNote

> *A modern, lightweight note-taking application and text editor designed with students in mind.*
---

Modern note taking applications and text editors have filled their features to the brim, hogging your computer's resources. Even worse taking away your precious time waiting for it to load. I often find myself in this situation, hoping for a fast yet functional application that would serve my immediate needs. 

FastNote is a **lightweight** note-taking application that has all the *necessary* features of any modern text editor:
- Create: creating new documents
- Read: opening and viewing existing files 
- Update: editing text
- Delete: deleting existing documents

## User Stories
- As a user, I want to be able to add a document to my collection of notes
- As a user, I want to be able to view a list of documents in my collection
- As a user, I want to select a document in my collection to view and edit it
- As a user, I want to remove a document from my collection
